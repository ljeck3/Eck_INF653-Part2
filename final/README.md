# INF653 Final – event Ticketing System REST API

## Description
This API allows a user to book a ticket to an event. This project is intended to cover a wide range of backend concepts.

## Getting Started

### Viewing the Website
Method 1: Visit online: <br>
Method 2: Run locally:
```
npm install
cd final
npm start
```

## Envrionment Variables Used
* DATABASE_URI (MongoDB)
* PORT
* ACCESS_TOKEN_SECRET (JWT)

## List of Endpoints
* /api/events
* /api/bookings
* /api/auth/register
* /api/auth/login
